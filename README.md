## Walmart Stock Analysis using PySpark

### Overview
This project analyzes Walmart stock data using PySpark in Databricks.

### Dataset
Walmart stock data (2012–2017)

### Skills Demonstrated
- Spark Session
- CSV Data Loading
- Schema Inference
- DataFrame Operations
- Aggregations
- Correlation Analysis
- Date Functions
- Filtering and Sorting

### Key Questions Solved
- Peak High Price Date
- Average Close Price
- Maximum and Minimum Volume
- Correlation between High and Volume
- Maximum High per Year
- Average Close per Month
